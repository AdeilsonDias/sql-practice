----SQL Practice - Análise de Dados

Exercícios práticos focados em análise de dados com SQL, utilizando cenários de negócio.

 ---📊 Casos desenvolvidos

1. Engajamento de Clientes
Identificação de clientes mais ativos com base em volume de transações e pontos acumulados.

2. Clientes Inativos
Listagem de clientes sem transações e cálculo de dias sem atividade.

 3. Comportamento de Resgate
Análise de consumo de produtos e gasto por cliente.

4. Categorias Populares
Identificação das categorias mais resgatadas e canais de origem.

--- 🛠 Tecnologias
- SQL
- SQLite
